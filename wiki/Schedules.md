
`F00B` - This file begins with 0x100 `uint16`s, one for each possible character. They tell how many schedule entries the character has. This block of schedule lengths is followed immediately by the schedules, in order, closely packed. 

Each schedule entry, of which there are a variable number per the preceding data,  is eight bytes. The function of the first byte is the hour at which the schedule entry takes effect. The function of the next three bytes is uncertain at this time. The fifth byte is the level. The last three bytes are an `xy24` for the location within the level. 


|**Field** | **Type**|
|-|-|
|Hour | `uint8`|
|Flags? Ends up as field 0x15 for the character | `uint8`|
|Script tie-in? | `uint16`|
|Level | `uint8`|
|Position | `xy24`|



Multiple entries for the same time probably represent random choices.

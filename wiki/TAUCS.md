
TAUCS stands for "The Annotated Unofficial Cythera Sources." These are a series of commented [RDASM](RDASM) files obtained by disassembling the script code in [Cythera Data](Cythera-Data), intended for such purposes as bug fixing / maintenance, critical commentary, and resolving questions about the game mechanics. Rather than just being a dump of output from DDASM, they have had symbolic names intelligently picked by their commentator/annotator and use appropriate symbolic constants for immediate values, to enhance readability. Any item marked with the status _correct_ or _complete_ in the table below has been checked with RDASM to verify that it compiles into virtual machine code completely identical to that found in the unmodified data file. Ones marked _complete_ additionally have been annotated.

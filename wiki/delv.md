
delv is a python module for manipulating the scenario files and other data of [Delver](Delver)-based games. 

Its github page is [https://github.com/BryceSchroeder/delvmod](https://github.com/BryceSchroeder/delvmod) 

To get the graphical editor [redelv](redelv), which uses delv as its backend, try: 

```
$ sudo easy_install redelvlib
```

You can then run redelv by typing in your terminal: 

```
$ redelv
```

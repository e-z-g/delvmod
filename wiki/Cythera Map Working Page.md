Entry points we have: 

* [Delver editor stamp](Delver-editor-stamp), we have several examples with human-readable names. 
* The game itself 
* List of names for things in [F004](F004), which include many names for tiles, e.g. "grass", "farmland" 
* The presumptive map resources, in [Cythera Data Subindex 127](Cythera-Data-Subindex-127) 
* List of zone names in [Cythera Data Subindex 19](Cythera-Data-Subindex-19) and [Cythera Data Subindex 20](Cythera-Data-Subindex-20) and other metadata 
We have reason to believe that the game has "zones" which are identified by an ID. Yet, save file editing has also told us that objects which move the player from one area to another (e.g. stairs) identify the area by means of a one-byte index. This is probably an index and not an ID, as all indicies from 0x01-0xBE inclusive are valid and every one after that is invalid. 

We would like to find the chain of resources to completely associate associate a subindex 19/20 entry with a name, and ideally figure out how the location indices in save files / objects correspond to them... 

The subindex 19 entries may be scripts that run when a new zone is entered, judging by 1424. Certainly they seem to contain at least one 81 ... 40 Script Type. 

Subindex 20 seems to relate to zones which have multiple areas with separate main game window title strings. For example, 140E has both the upper story of Pnyx and the Pnyx crypts, but you see the title of the game as "Pnyx" when you are on the upper story and "Crypts" when in the crypts. Since Subindex 20 (15xx) resources have no obvious reference to Subindex 19 (14xx) resources, nor 15xx's to  14xx's, something else must relate them both. It does not seem to be the 80xx map resource - e.g. 8009 has a header entirely blank except for the four bytes specifying its size, it has no reference to the resource 1500 that assigns the title "Underground City" to parts of the map 8009. Perhaps some kind of object is set up to trigger when the player enters these spaces, and run a 15xx script. 

The emerging picture is that the 14xx scripts might be executed when the player uses an object that transports them (like a hole or stairs), but that must not be the whole picture, because objects can take the player to different places on the same map, and the 14xx scripts do not appear to have any list of coordinates. Further, Save File Hacking indices seem to refer to an array with both map and destination coordinate information.

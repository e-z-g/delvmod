
Although a [Cythera Data](Cythera-Data) file produced by [Narthex](Narthex) will run, even though it is not an exact copy of the original (Narthex omits various debris that is present in the original file but not pointed to by any [subindex resource record](Delver-Archive)), preliminary experiments with modifying the data file were not successful. 

Initially, using modified files causing Cythera to quit with an error message about an incompatible scenario. This was due to a bug in Narthex, as suspected, but the possibility of a deliberate checksum existed.  

As of the present, though, experiments are still in progress. It is likely that remaining difficulties are also caused by subtle bugs in Narthex. Update: no, boneheadedly stupid bugs.

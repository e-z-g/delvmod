
A type of data found in [Cythera Data](Cythera-Data), that probably represents a compiled script. It is almost certainly distinct from the [AI Script Type](AI-Script-Type), but it is not known if the AI Scripts are interpreted directly by Delver, or if they are interpreted by a runtime implemented in the general purpose scripting language (i.e. the one this page discusses the compiled form of.) 

Current conjecture: code for a stack-based virtual machine. (Reasoning: apparent implicit operands imply some kind of stack or else very few and non-orthogonal registers. Stack-based virtual machines are easy to implement, and the compilers are much easier to implement than those for register machines.)
